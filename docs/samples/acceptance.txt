inner-rag 验收样例文档

验收用的测试句子是：紫罗兰色的量子齿轮会在每月第三个星期二回收三分之二的缓存分片。

验收判定标准：
1. /api/system/health 返回 healthy（模型侧至少一个 provider 可用）。
2. 上传本文档后，GET /api/doc?kb_id=<id> 中该文档 status 为 completed。
3. POST /api/chat/stream 的 sources 事件指向本文件，相关度合理（不是 0 也不是全部相同）。
4. done 事件的答案里出现「三分之二」，说明答案确实来自文档内容而不是模型自由发挥。
5. 追问「第一句里说的是什么颜色的齿轮」，答案应为「紫罗兰色」，用来验证多轮历史生效。
